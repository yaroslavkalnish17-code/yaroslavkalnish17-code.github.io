Правка сайта

Здесь можно поменять цены и тексты на сайте. Введите пароль, который вам дали.

Цены и тексты

Поменяйте, что нужно, и нажмите «Сохранить на сайте». Изменения появятся на сайте через 1–2 минуты. Цены пишите цифрами, например 6 000.

Настройка входа

Один раз: создайте на GitHub fine-grained токен только для репозитория сайта с правом Contents: Read and write. Токен шифруется паролем прямо в браузере и никуда не отправляется. Скачанный файл key.json положите в папку admin/ рядом с этой страницей.
